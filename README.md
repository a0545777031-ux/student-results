# تحليل نتائج الطلاب — Student Results Analysis

منصة سحابية رسمية ثنائية اللغة (العربية افتراضياً / الإنجليزية) لرفع ملفات نتائج
الطلاب (PDF / Excel)، قراءتها تلقائياً، استخراج نتائج كل طالب في كل مادة، وعرض
تحليلات ورسوم بيانية ومقارنات، مع لوحة تحكم كاملة للمدير.

---

## المزايا

- **واجهة ثنائية اللغة** بألوان رسمية حكومية، متجاوبة مع جميع الأجهزة (جوال/لوحي/حاسب)، والعربية هي الافتراضية (RTL).
- **تسجيل مستخدمين** مرتبط ببريد إلكتروني حقيقي، ويبقى الطلب **معلّقاً حتى يعتمده المدير**.
- **لوحة تحكم المدير**: اعتماد/رفض التسجيل، إيقاف الاشتراك وتفعيله، تغيير كلمات مرور المستخدمين، الاطلاع على تقاريرهم وملفاتهم، وحذف المستخدمين.
- **تغذية واجهة الموقع**: يعدّل المدير نصوص الصفحة الرئيسية (عربي/إنجليزي) من لوحة "محتوى الموقع".
- **رفع مجموعة ملفات دفعة واحدة** (PDF أو Excel).
- **قراءة تلقائية لملفات PDF** (نموذج «دفتر رصد الدرجات») حتى لو كانت النصوص العربية مشفّرة، واستخراج كل طالب على حدة مع درجاته في كل مادة وكل حقل (اختبارات قصيرة، أدوات تقييم، نهاية الفصل، المجموع) للفصلين.
- **اختيار الحقول المراد تحليلها** بعلامات تحديد، مع رسوم بيانية جذابة (أعمدة، دائري، رادار، مقارنات) وجداول.
- **تحميل النتائج** بصيغة **Excel** و **PDF** — والملف باسم الفصل الذي أدخله المستخدم (مثال: «الثالث متوسط أ.pdf»)، إضافة إلى تنزيل الملف الأصلي.
- **سحابي بالكامل**: يُفتح برابط من أي جهاز وأي مكان بعد النشر، وليس المتصفح فقط.

## بيانات دخول المدير الافتراضية

- اسم المستخدم: `Admin999`
- كلمة المرور: `123`

> يمكن تغييرها عبر متغيّرات البيئة `ADMIN_USERNAME` و `ADMIN_PASSWORD` قبل التشغيل الأول.

## التشغيل محلياً (للتجربة)

```bash
pip install -r requirements.txt
python app.py
# ثم افتح: http://localhost:5000
```

## النشر السحابي المجاني (ليصبح رابطاً يُفتح من أي جهاز)

### الخيار الأول: Render (موصى به — يوجد ملف render.yaml جاهز)

1. أنشئ حساباً مجانياً على <https://render.com>.
2. ارفع هذا المشروع إلى مستودع GitHub (أو استخدم "Deploy from Git").
3. في Render اختر **New → Blueprint** ووجّهه إلى المستودع؛ سيقرأ `render.yaml` تلقائياً.
4. سيقوم ببناء المشروع وتشغيله عبر: `gunicorn app:app`. سيظهر لك رابط عام مثل
   `https://student-results.onrender.com` — هذا هو الموقع السحابي.

> ملف `render.yaml` يُنشئ قرصاً دائماً (Disk) على المسار `data/` لحفظ قاعدة البيانات
> والملفات المرفوعة بشكل دائم بين عمليات إعادة التشغيل.

### الخيار الثاني: Railway

1. حساب مجاني على <https://railway.app> → **New Project → Deploy from GitHub**.
2. سيكتشف Python تلقائياً؛ أمر التشغيل موجود في `Procfile`.
3. أضِف Volume دائماً على المسار `/app/data` لحفظ البيانات.

### أي استضافة Python أخرى (VPS)

```bash
pip install -r requirements.txt
gunicorn app:app --bind 0.0.0.0:8000 --timeout 120
```
ثم اربطها بنطاقك عبر Nginx. يُنصح بضبط `SECRET_KEY`.

## متغيّرات البيئة (اختيارية)

| المتغيّر | الوصف |
|---|---|
| `SECRET_KEY` | مفتاح تشفير الجلسات (يُولّد تلقائياً إن لم يُضبط — اضبطه في الإنتاج). |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | بيانات دخول المدير (افتراضي `Admin999` / `123`). |
| `ADMIN_EMAIL` | بريد المدير لاستلام تنبيه عند كل تسجيل جديد. |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM` | لتفعيل **إرسال بريد حقيقي** (تنبيه المدير + إشعار المستخدم عند الاعتماد). |

### تفعيل البريد الإلكتروني الحقيقي

النظام يعمل بدون بريد (الاعتماد يدوي من اللوحة). لتفعيل الرسائل الفعلية، اضبط متغيّرات
`SMTP_*`. مثال باستخدام Gmail (مع «كلمة مرور تطبيق»):

```
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your@gmail.com
SMTP_PASS=app_password_here
SMTP_FROM=your@gmail.com
ADMIN_EMAIL=admin@yourschool.com
```

أو استخدم خدمة مثل [Resend](https://resend.com) / [Brevo](https://brevo.com) (باقات مجانية).

## ملاحظة حول قراءة ملفات PDF

قارئ الـ PDF مُعدّ ومُختبَر على نموذج **«دفتر رصد الدرجات»** الرسمي (وزارة التعليم):
الأعمدة = المواد، والصفوف = حقول الدرجة لكل طالب، مع اسم الطالب ورقم الهوية.
جرى استخراج ١٧ طالباً و١٥ مادة و٨ حقول بدقة من الملف النموذجي.
إذا اختلف تنسيق ملفاتك، أرسل نموذجاً وسنضبط القارئ ليطابقه. كما يدعم النظام رفع ملفات
**Excel** مباشرة (تنسيق طويل: الاسم/المادة/الفصل/الحقول، أو تنسيق بسيط: الاسم ثم أعمدة المواد).

## البنية التقنية

- **الخادم**: Python + Flask، قاعدة بيانات SQLite (بدون إعداد).
- **قراءة PDF**: pdfplumber + pikepdf + fontTools (فك تشفير الخطوط CID واستعادة العربية).
- **Excel**: openpyxl. **PDF**: reportlab مع مُشكّل عربي مدمج (`ar_shape.py`) — لا يحتاج مكتبات خارجية.
- **الرسوم البيانية**: `minichart.js` — محرّك رسم مدمج بالكامل (لا يعتمد على أي CDN)، مناسب للشبكات الحكومية المقيّدة.

## هيكل المشروع

```
app.py            # خادم Flask، المصادقة، اللوحة، رفع/تحميل الملفات
parser_core.py    # قارئ PDF واستخراج نتائج الطلاب
data_io.py        # قراءة/كتابة Excel وتوليد تقارير PDF
ar_shape.py       # مُشكّل النص العربي لملفات PDF
templates/        # صفحات HTML (رئيسية، دخول، تسجيل، لوحة المستخدم، لوحة المدير)
static/           # CSS + JS (i18n، لوحات، الرسوم البيانية)
fonts/            # خط يدعم العربية لملفات PDF
requirements.txt, Procfile, render.yaml, runtime.txt
```
